# ⚔️ Héroe del Overworld — Plataforma Educativa Interactiva

¡Bienvenido al Overworld, valiente héroe! Esta es una aplicación educativa modernizada con arquitectura profesional **Frontend-Backend**, almacenamiento persistente local en **SQLite** y un sistema seguro de inicio de sesión con **PIN**.

---

## 🛠️ Requisitos previos

Para ejecutar la aplicación localmente, solo necesitas tener instalado **Node.js** en tu computadora:

* [Descargar e instalar Node.js](https://nodejs.org/) (se recomienda la versión LTS).

---

## 🚀 Cómo iniciar la aplicación (En un solo paso)

1. Abre una terminal (o consola de comandos) en la carpeta donde descomprimiste este proyecto.
2. Ejecuta el siguiente comando para instalar las dependencias e iniciar el juego:

```bash
npm install && npm start
```

3. **¡Y listo!** El servidor se iniciará automáticamente y se abrirá una pestaña en tu navegador web en la dirección `http://localhost:3000`.

---

## 📋 Características de la versión moderna

1. **Persistencia de progreso (SQLite)**: Tus diamantes (estrellas), logros de trofeos y progreso de misiones se guardan automáticamente de forma segura en una base de datos local (`database.sqlite`).
2. **Autenticación Infantil Segura**: Crea tu perfil con tu nombre de usuario, selecciona tu avatar emoji favorito y define un PIN secreto numérico para que nadie más pueda tocar tu inventario.
3. **Misión Parcial Completa**: Domina las misiones de Matemática, Lengua e Inglés (incluyendo los divertidos desafíos visuales de verdadero/falso de inglés basados en fotos y animales del Overworld).
4. **Tabla de Líderes**: Compite de forma sana y divertida con tus compañeros o hermanos para ver quién consigue la mayor cantidad de estrellas y trofeos en el Overworld.
